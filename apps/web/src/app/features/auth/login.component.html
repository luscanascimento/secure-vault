Encrypted at rest

Your notes, sealed behind real cryptography.

Every note body is encrypted with AES-256-GCM before it touches the database. Passwords are hashed with Argon2id. Sessions rotate, and a replayed refresh token ends all of them.

  • AES-256-GCM authenticated encryption for note contents
  • Argon2id password hashing with salt + application pepper
  • Rotating refresh tokens in httpOnly, SameSite cookies
